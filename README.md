# The Morning Ledger

A daily newspaper-style news briefing with a finance focus: world, Germany & Europe, India and Asia news, each story linked to what it means for stocks, rates, FX, commodities and crypto.

- `index.html` – the newspaper layout (static, no build step)
- `edition.json` – today's edition, rewritten every morning by an AI news agent (~06:34 Berlin time)
- `editions/YYYY-MM-DD.json` – archive of past editions; `editions/index.json` lists them, newest first

Hosted on Vercel as a static site. Information only, not investment advice.
